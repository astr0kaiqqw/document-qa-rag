# Оставшиеся ограничения

1. **Надёжного semantic no-answer нет.** SQuAD v1 checkpoint выделяет span даже из нерелевантного текста. На исходных 2/2 и дополнительных 4/4 no-answer вопросах false answer rate 100%. Не следует показывать candidate как достоверный факт. Структурный отказ работает, но не заменяет semantic rejection.
2. **Переносимость качества не доказана.** На старом audit eval F1 pipeline 41.02→48.59%, а на новой документации Python/NumPy 72.80→56.55%. EM новой выборки 37.5→25%, Recall@1 100→75%. После этого параметры не подбирались. Правильное соблюдение token budget сохранено, но конфигурация 96 не универсальна. Для устойчивой настройки нужны новые dev документы; эти test examples теперь просмотрены.
3. **RU/KK retrieval регрессировал.** По одному вопросу на язык в общем audit corpus: финальный pipeline F1 0 против 66.67% RU и 100% KK baseline. Это реальные регрессии, не статистическая оценка языков в целом. Oracle сохраняет часть правильного контекста, но retrieval/selection теряют evidence.
4. **Границы модели несовершенны.** Часты лишние слова `by`, `is`, `for`; offsets и whole-word rules не исправляют обучение. Oracle EM всего 15% на старом eval. Отключение word constraints возможно через `QAModel(whole_words=False)`, но допускает фрагменты слов. Идентификаторы/дефисные слова защищены; специальные случаи могут потребовать дополнительных размеченных boundary examples.
5. **Лимит длины ответа.** По умолчанию 30 wordpieces; gold backup policy требует 33. Лимит настраивается, но прошлое увеличение до 90 без переобучения не улучшило predictions; arbitrary length bonus не включён.
6. **История обучения недоказуема по одному notebook.** Нет Colab trainer_state, hashes исходного checkpoint и actual tokenized features; source/output notebook расходятся. Нельзя доказать, что shift испортил весь training set. Исправленная подготовка данных протестирована, фактическое обучение не выполнялось.
7. **PDF extraction не идеален.** Нет OCR и восстановления формул/склеенных слов. Private-use glyph warnings показывают проблему, но не исправляют её. Poppler отсутствует, визуальный аудит PDF не проведён. Raw pages сохраняются как text pypdf, не как связь каждого символа с PDF glyph boxes. DOCX loader по-прежнему читает body paragraphs, не tables/headers.
8. **Длинные вопросы/слова.** Oversize embedding queries отклоняются явно; suffix не обрезается. Единичное слово, не помещающееся в chunk budget, тоже вызывает исключение. Tokenization всего длинного QA context занимает линейную память, хотя model forward и сохраняемые candidates ограничены по окнам.
9. **Metadata и сохранение индекса.** Document/page metadata доступны в текущем RAGPipeline session. Существующий VectorStore.save/load сохраняет только vectors/chunk strings, не восстанавливает весь pipeline provenance. Между запусками metadata нужно построить заново загрузкой документа.
10. **Оценки не confidence.** Cosine показывает близость evidence; log-softmax концентрацию token logits; CLS margin некалиброван. Условные distributions между окнами зависят от длины контекста. QA/RRF — экспериментальные opt-in, default retrieval может выбрать плохой answer из самого близкого chunk. Противоречащие друг другу passages не разрешаются семантически: альтернативы и источники доступны для проверки, автоматического fact-checking нет.
11. **Наборы малы.** Старый eval уже был просмотрен, dev содержит 6 answerable; новый — 8 answerable из 4 documentation excerpts. Это не multi-document multilingual production benchmark, нет confidence intervals и не проверена возможная встречаемость текстов в pretraining. Gold задан вручную; модель не использовалась для разметки.
12. **Окружение ограничено одной платформой.** Существующий Python 3.14.7/macOS ARM64; зависимости закреплены без установки/upgrade. Стандартный HF QA pipeline в этой версии недоступен. Сравнение выполнено прямым вызовом того же fine-tuned model, а не заменённой QA-моделью. Новое окружение и training dependencies требуют отдельной проверки.

Ни один из этих пунктов не следует считать исправленным только потому, что 128 unit/integration tests проходят.
